## 一、自我开刀：原 v2.0 调研方案中存在的 4 处“技术杂糅”与真实脚本冲突

在阅读完 38 篇论文后，原报告把各篇最优技巧拼成了“全明星阵容”，但如果直接往 `2×8 H800`（`gpu34 + gpu38`）上写代码，会立刻撞上以下 **4 个数学与工程打架点**：

### 1. 奖励聚合三套归一化叠床架屋（`PhyCAD HBA` × `GDPO` × `POW3R` 数学冲突）
- **问题诊断**：
  - `PhyCAD HBA` 的核心定理（$\lambda_L = 1.0 > 2\lambda_w = 0.50$）要求同层内部排序项必须严格有界于 $\tilde{A}_i \in [-1, 1]$（通过分位秩 `PeerRank` 实现）；
  - `GDPO` 则是对多个连续指标在整个采样组 $G$ 内各自做零均值单位方差白化 $\frac{r^{(k)}-\mu}{\sigma}$ 再求和，其值域无界（常达 $[-2.5, +2.5]$），且把构建失败样本与合格样本混在同一均值方差池里——一旦嵌入 `HBA` 会直接**击穿 $\lambda_L > 2\lambda_w$ 严格跨层保序不等式**；
  - `POW3R` 依赖类内标准差估计动态调整 Rubric 权重，原文明确要求有效样本数 $\ge 0.75G$（$G=16$ 即至少 12 条）。而在我们的分层短路设计中，只有通过全部硬门禁的 `$L_3$ 幸存者`（$G=8$ 中往往仅 2–4 条）才会调视觉裁判——在 $n=2\sim 4$ 的小样本上算 `POW3R` 标准差纯属统计噪声！
- **去杂糅裁决**：**保留 `PhyCAD HBA` 作为唯一主骨架，在在线 RL 中直接砍掉 `GDPO` 与在线 `POW3R`**！$L_0\sim L_2$ 同层仅按确定性违例计数排 `PeerRank`；$L_3$ 合格层直接用**正反双序成对锦标赛胜率**生成有界 `PeerRank` $\in [-1, 1]$。

### 2. Token 级优势四重篡改破坏零均值平衡（`GVPM` × `CDP ATC` × `SRaR` × `RECAP` 冲突）
- **问题诊断**：
  - 若在 `GSPO-token` 上同时开启 `IterCAD GVPM`（将半截合法前缀的负优势截断为 $\max(\hat{A}_g, 0)$）、`WebCatalyst ATC`（按 JS 调用栈缩放 `0.5× ~ 1.5×`）、`SRaR`（加轮次偏置）和 `RECAP`（加压缩 KL 优势）：仅 `GVPM` 的单边非负截断就会使组内正优势总和显著大于负优势总和，导致策略向冗长啰嗦和过度自信漂移，再叠三层局部乘加项会让梯度方向完全不可解释。
- **去杂糅裁决**：**MVP 阶段砍掉 `CDP ATC`、`SRaR` 在线步骤裁判与 `RECAP` 额外前向**；仅保留 **`GSPO`（按轮/段长度归一化似然比）+ `CompactionRL` 全局可训输出 Token 总数归一化 + 沿用 SFT 的 5 条坏轮 `loss_mask=0`**。

### 3. 实查三大验收脚本暴露出的 3 个隐蔽漏洞与耗时陷阱（必须在 RL 前修补）
1. **`verify_xhs_output.cjs`（第 473–508 行）存在两个致命假阳性漏洞**：
   - 第 500 行固定 `waitForTimeout(450)` 后截全屏算 `pixelMad >= 1.5`：若场景本身带 `requestAnimationFrame` 自动微转，哪怕放一个完全没绑事件的假 `<button>`，450ms 后画面也会因自转而变化，白拿 `L3_plus_ui_control_effect = true`！
   - 第 503 行用的是 `page.screenshot()`（含 HTML HUD 浮层）而非仅截 WebGL `<canvas>`：点击按钮只弹出一个 HTML 文本框而 3D 场景毫无变化也能混过 `mad >= 1.5`！
2. **`check_2d_v2.mjs`（第 133–552 行）包含 15+ 项严苛布尔断言**：
   - 若直接用 `report.ok`（0/1 二值）做早期 RL 奖励，任何一处轻微文字重叠或循环接缝速度跳变都会和白屏崩溃一样拿 `0` 分，导致高比例零方差死组；必须把这 15+ 项按严重度归并进 `L0 / L1 / L2` 三级阶梯并利用 `issues.length` 给出同层排序梯度。
3. **`cad_inspect.py`（第 606–737 行）默认跑 3 次无头 Chromium 渲染**：
   - 对每个候选依次跑 `views_grid.png` + `section_view.png` + `exploded_view.png`（每次 Node+Chromium 子进程最高 60s 超时）；在在线 RL 中，**对 `issues != []`（语法错/非流形/布尔干涉/探针挂）的样本必须传 `--no-render`**（纯 OCCT `<0.8s` 秒判），仅对 `ok == True` 的 $L_3$ 样本开渲染供视觉比对，可立省 `85%+` 沙盒耗时！

### 4. 五阶段流水线过重 & `384K` 全程在线 RL 算力账不现实
- **硬算力账**：在 `2×8 H800` 上，如果一开始就让 `Qwen3.8-27B` 从零跑 `384K`、160 轮、含 15 张高清图的 $G=8$ 在线 rollout，单题一组采样连同等候沙盒就要 15–30 分钟，一天跑不了 30 步！
- **跨轨打架真相辨析**：`GRPO / GSPO` 是在**同一道题 $x$ 的 $G$ 条候选内部**算相对优势，只要三轨共用统一的 `HBA` 有界优势值域 $[-3.25, +3.25]$，不同轨道之间**根本不存在奖励量纲污染**！真正需要拆成单轨 LoRA + `OPD` 合模的前提只有一个：“沙盒资源冲突或某轨迭代周期远快于其他轨（如纯 CPU 的 CAD 可以一天跑 300 步，而重度 WebGL 3D 很慢）”。

## 二、收敛后的极简三阶段落地主线（从“6 轮杂糅”砍成“SFT + 短程精修 RL + 按需合模”）

1. **Phase 0（当前收口）：XHS 标准三轨 SFT（1 Epoch + 通用锚点 + 契约钩子 `2×` 权重 + 保留 9 节压缩 `<summary>` Loss）**
   - 修补上述 3 个验收脚本小补丁，顺手将每题高分教师成品截图存为冻结 `Visual Anchor`。
2. **Phase 1（RL 破局 MVP，最高 ROI）：短窗口多轮“诊断-精修（Bounded Repair/Refinement）”在线 RL（`32K–64K` 窗，限 `3–5` 轮，`$0` API 费）**
   - **核心切法**：不从空白目录跑 384K 百轮马拉松，而是直接拿 **Phase 0 SFT 模型自己在训练题库上生成的初稿工作区（含真实几何干涉、遮挡、缺交互或低审美瑕疵，筛除已满分与完全无法启动的极端题）** 作为起点，给 `27B` `3–5` 轮预算去“跑检查器/看渲染图 $\to$ 定位缺陷 $\to$ 修代码重验”！
   - **为什么这一招四两拨千斤**：完全避开了 `auto-compact` 跨段难题（无需 `RECAP / CompactionRL` 即可先吃下核心红利！），单步采样耗时缩短 **`10×`**，且精准命中 `3DCodeEdit` 揭示的 `27B` 最大软肋（`<0.6` 轮自审惰性与 `G4/C` 局部重构瓶颈）！
3. **Phase 2（仅在确认单轨异步分训更快、或需攻克从零 384K 压缩时解锁）**：
   - 若 CAD LoRA 与 3D/2D LoRA 分开异步迭代，用 `DeepSeek-V4` 同底座缓存末层 Hidden State 全词表反向 KL（$G=1$）花几百步无损合入统一 `Qwen3.8-27B`；若发现跨压缩恢复掉分，再挂载 `CompactionRL` 跨段折扣。

## 三、全系统唯一、无冲突的四层优势合成公式（三轨通用，50 行代码可实现）

对任意题目 $x$ 采样的 $G=8$ 条轨迹 $\{y_1, \dots, y_G\}$：

1. **确定性脚本秒级定层 $L_i \in \{0, 1, 2, 3\}$ 与违例数 $v_i \ge 0$（0 次 VLM 调用）**：
   - $L_i = 0$：缺交付文件、AST 违规、构建/加载异常、`pageErrors / consoleErrors > 0`；$v_i =$ 错误条数。
   - $L_i = 1$：静态几何/版式硬违例（CAD 非水密或布尔干涉 `>0.05 mm³`；2D 画面空白 `<0.008`、SVG 裁剪越界、剥离伪装 `overflow:hidden` 后文字重叠；3D WebGL 空白或越界）；$v_i =$ 静态违例项数 + 归一化干涉量。
   - $L_i = 2$：动态/参数化探针未过（CAD `--probe` 零响应或报错；2D 乱序 seek 不一致、循环跳变、`#scrub/#play/#pause` 失效；3D 冻结时钟后纯 `<canvas>` 拖拽 `OrbitControls` 或触发控件零像素变化）；$v_i =$ 失败探针数。
   - $L_i = 3$：上述硬门禁 **100% 全通（`issues == []`）**！
2. **同层有界排名分 $\tilde{A}_i \in [-1, 1]$**：
   - 对 $L_i \in \{0, 1, 2\}$：直接按 $-v_i$ 在同层子集 $\mathcal{S}_{L_i}$ 内算归一化分位秩 `PeerRank`（平局容差 $10^{-3}$，单样本层置 $0$）。
   - **仅对 $L_i = 3$ 子集 $\mathcal{S}_3$**：用独立卡上**冻结的视觉裁判**（冻结 Base/教师或多裁判交叉，绝不用正在更新的 Actor 自身权重！）执行带前置一句 `"reasoning"` 的**正反双序成对比较**（含与该题冻结 `Visual Anchor` 的底线比对，若低于锚点扣固定罚分），按净胜率算同层 `PeerRank` $\tilde{A}_i \in [-1, 1]$。
3. **严格保序 `HBA` 标量合成 + 组内中心化（无标准差爆炸除数）**：
   $$R_i^{\mathrm{HBA}} = 1.0 \cdot L_i + 0.25 \cdot \tilde{A}_i, \qquad \hat{A}_i = R_i^{\mathrm{HBA}} - \frac{1}{G}\sum_{j=1}^G R_j^{\mathrm{HBA}}$$
   （注：满足 $1.0 > 2\times 0.25$，任何 $L_3$ 必比 $L_2$ 高出至少 $+0.50$；采用 `GiGPO / Dr.GRPO` 无 `std` 除数中心化，彻底防止 `8 过 1` 时除极小标准差炸穿权重！）
4. **策略更新目标（`GSPO` + `TITO` + 全局可训 Token 归一化 + 轻量 KL $\beta=0.02$）**：
   - 仅对未命中 5 类坏轮掩码的可训 `assistant` token 集合 $\mathcal{M}$，按 $\frac{1}{|\mathcal{M}|}$ 归一化损失，配 `IcePop` $\rho \notin [0.5, 2.0]$ 异常保护。
