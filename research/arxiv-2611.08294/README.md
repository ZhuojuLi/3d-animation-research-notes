## 1. 核心问题与作者发现的真实痛点

1. **“渲染零报错 $\neq$ 动画可用”与全网开源 Manim 语料的惊人脏度（Sec 1 & Appendix A.1 Table 5）**：程序化动画即使成功导出视频，仍普遍存在**标题与表格重叠、元素冲出画幅被裁切、标签字号过小不可读、前序步骤未清理残留或计算/概念漏讲**等缺陷。作者对四大来源共 **42,507** 条输入做实跑体检，揭露了触目惊心的真实现状：

| 原始数据来源（Appendix Table 5） | 原始输入数 | 首轮可渲染率（`1st renders`） | 经 `Qwen3.8-27B` ≤10 轮修订后达标录取数（均分 $\ge 3.75$） | 去重防泄漏后终库数 | **终库中首版即达标无需修改占比（`Unchanged`）** |
| --- | ---: | ---: | ---: | ---: | ---: |
| Wikipedia STEM 合成题（63.97 万词条三级筛出） | 22,058 | 56.5% | 15,908 *(72.1%)* | 15,537 | **仅 `13.1%`** |
| HF 7 大开源社区合集（原 20,976 条，1/3 直接崩） | 13,768 *(已筛可渲染)* | 100.0% | **4,284 *(仅 31.1%！)*** | 4,284 | **仅 `22.6%`** |
| `JanusCode-800K`（Manim 子集，原 8,316 条） | 6,365 | 56.4% | 4,018 *(63.1%)* | 3,944 | **仅 `4.3%`！** |
| `ManimBench` 训练集（多数静态单图无视频） | 316 | 41.1% | 269 *(85.1%)* | 269 | **仅 `15.2%`** |
| **合计（`ManimData` 终库）** | **42,507** | **70.5%** | **24,479** | **24,034** | **仅 `13.4%`（`86.6%` 必经多轮返修！）** |

2. **基准污染、分布偏移与局部布局“打地鼠震荡”**：
   - 公开训练模型污染严重：`JanusCoder-8B` 训练集直接包含了 **`71/100` 道 `ManimBench` 测试题**（Table 2）；
   - 教师-学生状态分布偏移：强教师（`Qwen3.8-27B`）轨迹无法覆盖小模型（`4B`）推理时自造的故障态；
   - 局部平移死循环（Sec 5.4 & Fig. 6）：第 1 轮把交易列表下移避开顶部进度条却导致底边越界被切，第 2 轮又把它移回原位恢复重叠。

## 2. 方法论、数学公式与沙盒/验证器工程细节（含 Appendix 关键配置与 Prompt 要点）

### 2.1 `Qwen3.8-27B` 渲染引导闭环、2,219 张实跑验证 API 卡与停顿点硬检（Sec 3 & Appendix A Tables 6–7）

| 闭环组件（Appendix Tables 6–7） | 精确工程配置与防坑规则 |
| --- | --- |
| **渲染环境与预算** | `ManimCE v0.19.1` + 8 大领域插件（`physics / chemistry / ml / dsa / eng / circuit / automata / code-blocks`），480p，每题上限 **`10` 次渲染** |
| **2,219 张实跑 API 卡片检索** | 官方文档（1,569 张：822 方法/属性、358 类、218 函数/常量、171 指南/模块）+ 插件（356 张：由 `Qwen3.8-27B` 读源码编写并**离线实跑渲染验证，最多按报错重试 3 次**，含 21 条能力 Recipe）+ `manim_skill`（233 条规则 + 61 场景）；每步 2–4 查询，经 **`Qwen3-Embedding-8B` + `Qwen3-Reranker-8B` 取 Top-10** |
| **停顿点确定性布局硬检 $\ell$** | 在**动画停顿帧（Animation Pause Points）**读取对象几何坐标，确定性检出三类缺陷：**① 物体越出画框、② 文字相互重叠、③ 标签过小不可读** |
| **Reviewer 与防退化候选回滚** | `Qwen3.8-27B` 看 `(需求 x, 代码 c, 8 帧均匀抽帧)` 对**需求对齐、内容完整度、视觉清晰度、动画质量**打 `1–5` 分并写挑刺 $f$；仅当均分上升且**`对齐`与`完整度`单项跌幅均 $\le 0.5$** 时才替换 $c^*$；若最新候选这两项比 $c^*$ 跌超 `0.5`，下轮自动回退以 $c^*$ 为修订起点 |
| **错位抽帧二次确认早停** | 均分 $>4.0$ 且四维全部 $>3.5$ 时，**必须在平移错位采样的另一组 8 帧（Shifted Set of 8 Frames）上通过第二次独立复审**才允许早停 |

### 2.2 五角色条件轨迹 SFT 与“自生故障态 + 双向交换顺序成对盲评”修订 RL（Sec 4 & Appendix B）
1. **五角色混合 SFT（`305,452` 条样本训单一 `Qwen3.5-4B`，Table 8）**：
   - 目标函数：$\mathcal{L}_{\mathrm{SFT}}(\theta)=-\mathbb{E}_{(\rho,z,y)\sim\mathcal{D}_{\mathrm{SFT}}}\log\pi_\theta(y\mid\rho,z)$；
   - 样本配比：`Writing`（`24,034`，学终态 $c^*$）、`Execution repair`（`14,587`，崩溃代码 $\to$ 可渲染代码）、`Quality revision`（`32,683`，低分代码+$f$+$\ell$ $\to$ 涨分代码）、`Reviewing`（`46,965`，代码+8 帧 $\to$ 四维分+挑刺）、`Retrieval queries`（`187,183`，需求+报错/挑刺 $\to$ 2–4 条检索词）。
2. **自生状态无参考修订 RL（Revision RL on Self-Generated States）**：
   - SFT 模型在独立题池首轮自生成：崩溃则构造**修复态** $z^{\mathrm{rep}}=(x,c,e,\mathcal{K})$；渲染成功未达早停则用模型自评 $f$ + 硬检 $\ell$ 构造**挑刺态** $z^{\mathrm{crit}}=(x,c,f,\ell,\mathcal{K})$。每态采 $G=8$ 个修订，**近重复微改代码直接给 `0` 分防刷分**！
   - **修复态奖励公式（Eq. 2）**：崩溃给 `0`；渲染成功由 `Qwen3.8-27B` 评对齐与完整度均值 $q(c')\in[1,5]$（值域 $[0.75, 1.25]$）：
$$
r_{\mathrm{rep}}(c') = 1 + \frac{q(c') - 3}{8}, \qquad q(c') = \frac{q_{\mathrm{align}} + q_{\mathrm{complete}}}{2}
$$
   - **挑刺态双向交换顺序成对偏好公式（Order-Swapped Pairwise Reward, Eq. 3）**：崩溃给 `-1`；渲染成功由 `Qwen3.8-27B` 按 `(new, input)` 与 `(input, new)` **正反双序盲评**（偏好 $b_1, b_2 \in \{\mathrm{new}, \mathrm{input}\}$），彻底滤除位置偏置与微小分差噪声：
$$
r_{\mathrm{crit}}(c') = \begin{cases}
+1, & b_1 = b_2 = \mathrm{new}\text{（正反两次一致判新版更优）} \\
-1, & b_1 = b_2 = \mathrm{input}\text{（正反两次一致判原版更优）} \\
0, & \text{otherwise（前后矛盾或平局归零）}
\end{cases}
$$

## 4. 作者踩坑复盘与对我们 Qwen3.8-27B 三轨项目的落地启发（明确标注工程推论）

1. **【论文实证大坑 → VLM 绝对打分在 `<0.25` 分差区纯属噪声（`29%` 一致率），RL 必须走“正反双序成对盲评 + 微改归零”】**：
   - 论文事实：Table 10 证明绝对标量分微差不可信，而 Eq. 3 用 `(+1 / 0 / -1)` **正反交换顺序两次一致才给奖 + 近重复代码强制置 0**，配非对称裁剪 `[0.8, 1.28]` 仅训 **20 步 RLOO** 就把闭环渲染率从 `88.6%` 推至 `96.6%`。
   - *【我方工程推论】*：我方 Track 1（Three.js）与 Track 2（2D Web Canvas/SVG/GSAP 多文件工程，注：我方不走 Manim）在做自生状态修订 RL 与 Best-of-2 择优时，**应全面采用 50/50 正反翻转头对头盲评一致判胜机制，并对 AST/行数微改样本直接赋 0 分**。
2. **【论文实证定位 `Qwen3.8-27B` 的上限与阿喀琉斯之踵】**：
   - 论文事实：Table 2 与 Table 11 形成绝妙互证——`Qwen3.8-27B` 单轮无文档检索时渲染成功率仅 `39.8%`，但在双方都跑通的开放教学动画上**人工盲评以 `23 : 11` 压倒性击败精调 4B 模型（`VQ=3.09` 超越 `GPT-4o` 的 `2.87`）**！
   - *【我方工程推论】*：说明 `Qwen3.8-27B` 的构图审美与教学叙事底子极厚，核心瓶颈不在“笨”而在“单轮硬写易踩 API/布局坑”，用长程多轮自检轨迹 SFT + 故障修复 RL 刚好精准命中其最大提分杠杆。
3. **【论文实证工程细节 → 停顿点包围盒硬检 + 错位抽帧二次确认早停】**：
   - *【我方工程推论】*：直接启发我方 `check_2d_v2.mjs` 与 Three.js 验收器在关键停顿态测文字重叠/出界/最小可读字号，并在高分早停前换一组偏移时间戳重抽帧复核，根绝偶发好帧漏网。
