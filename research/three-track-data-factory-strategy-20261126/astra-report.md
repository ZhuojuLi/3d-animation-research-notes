## 1. 总体裁决与核心分歧

**有条件通过。可以立项做同栈重制和分轨验收，现有证据不足以批准首周 300–500 条或第三周全参合训。** 五项修正决定预算去向。

### 2.3 主提案第三章 · 分类树和“80% 复用”

每轨若预算是 400–600 个**独立入库任务**，均分 36 叶仅 11.1–16.7 题/叶，再交叉四种任务形态只剩 2.8–4.2。若预算指尝试次数，双合格选一即使全成功也最多 200–300 题。叶共享、多标签、同题重采均不增加独立样本数。建议选一个主采样族做账，保留平权语义多标签；题目与 starter 的共同祖先绑定 split。高频需求须由真实请求抽样验证，目前只能提出候选。第三节列出两树全量映射。

2D 四族 × 3 题，gold 12/12、bad 12/12、三代表样本三次冷启 9/9 同哈希；均为夹具试验。**模型首答基线仍缺，SVG 也未由 Canvas 成绩验证。** 静态风格图适合 A06、A07 轮廓、A05L03 配色，限定为色彩/构图评分。A01 杆长、A02 光路相位、A04 算法步骤、A08 数据值和滑块响应禁止以生成静帧作真值，首批这些题免文生图；确需结构图时用已知数值生成示意图。修复/编辑可给真实 starter，healthy 保留原样。非周期的阻尼、排序、生长、一次性 UI 转场分别验终止状态和 replay，周期题另测接缝前后的位置/速度，仅比 t=0 与 T 两张图会放过硬跳。[种子校准报告](../../3d-animation-agent/reports/round2-line-c-seeds-20261124-001/REPORT.md)

**不采信复用 80% 的工期承诺。** 合成器的 API 调用、JSON/ID 锚点验证、图编码、P07 矛盾回执拒绝和分离 solver 提示可共用。`_build_synth_prompt` 强制真 mesh、PBR、WebGL 和 __3D_STATE__，`synthesize_and_audit_one` 写死 img23d/generation，`write_runnable_outputs` 写死 loop=False。它也未实现 repair starter、healthy 零改动或渲染器本身。现有 2D checker 要求 __getSceneState、__getVisualState、#canvas 截图、实际 scrub、像素和状态对应。Canvas 要查清屏残影、伪随机与逆序 seek；SVG 要查 DOM/transform、viewBox、文字裁切、CSS/SMIL 时钟与实际绘制一致，不能要求 Canvas 的 willReadFrequently。两者都要冻结字体/DPR/时钟并屏蔽 HUD，比较主体 ROI；逐字节重复适用于固定环境同一时刻，跨引擎应使用几何约束与容差。先交一个 Canvas、一个 SVG 的真假动/回拖/接缝反例包，再按实际未改函数、改动函数、全新测试和工时分开估算。`合成器`（本地附件未发布） · `2D 检查器`（本地附件未发布）

**建议的账本字段。** 分轨及子桶报（1）独立家族/题键、记录数、重复曝光，（2）实际编码输入含图与长度分位/截断删除数，（3）非 mask U 含最终 EOS，（4）各段权重及 W，（5）每个 optimizer step 实际分母 D、各轨 Σw·CE/D、跳步与梯度范数。合计 W 不能当作各轨梯度同向的证明。packing 后要看每步混合与梯度累积，DP 汇总去副本；按轨组包只作对照，禁止只调 loss_scale 声称 U 已变。优先增独立构型与真实失败样本，第一轮每题最多一次曝光，不硬补 CAD 的 18%。对长 3D 用有界观察返修和干净停机控长，把 ≥90K 的有效闭环单列成本/收益，不直接切尾。

45+18+17=80，剩余两桶必须合为 20，提案给的上下限任取会得到 97–103%（取单轮 5–8 时）。仅作候选可先锁定 **45/18/17/7/13=100% U**，L2 计在 3D、L3=0，单轮锚点只记一次，通用回放独立记账。冻结同模板同 family split 的合格池后才估算是否可达；短轨供给不足时改比例或推迟 C。27B 是同一套权重，路由标记需要配合每题真实可见工具 schema、独立工作区与后端、准确文件接口；训练与测试都用产品会出现的自然语言。单独计 CAD 误调 esbuild、2D 误用 THREE/伪造 WebGL 状态、3D 误开本地服务、跨轨修改无关文件的任务数。共享 Read/Bash 等真实公共工具无需改名。检查无标签任务与显式标签任务的性能差和实际工具调用，防止只记住模式头。
