## 一、联合结论速览（总体裁决：有条件通过，5 项关键修订已合入）

双方一致认可核心主线：**坚守“3D 动画 / CAD 建模打印 / 2D 动画”三轨范围，划清与小红书 `3DCodeFactory` 的交付契约边界；重点吸收其方法论与高审美题图种子，通过两级分类树 + 核心采样族把 CAD 与 2D 快速标准化；坚持先基线/成本哨兵/小规模干扰探针、再分批放量。**

经 Astra 实扫本地 `217` 个小红书分片（`167.52 GB`、`16,661` 行 JSONL）及实查脚本源码，对主提案做出 **5 项硬修正**：

1. **L3（直接混灌小红书原始 Three.js 完整轨迹）从“10–15% 候选”修订为“现阶段 0%（彻底砍掉）”**：Astra 对本地 217 个分片全量内存实扫并用真实 `Qwen3.8-27B` tokenizer 编码，仅找到 **3 条**原题起步、工具闭合、自然收尾的未切 Three.js 主轨迹（分片 `00164/19`、`00180/6`、`00396/53`），仅文本模板即高达 **`335,545` / `302,683` / `349,763` tokens**——在当前 `180,224` 乃至原生 `262,144` 训练窗口下可用数为 **0 条**！
2. **L2（抽小红书题面 + 参考图重制同栈数据）获优先拨款，但须补“抽图落盘 + 我方留出集去重 + 注入真实运动机理”三道前置工程**：217 分片实扫确认 **`1,128` 个独立 Three.js 主任务键**（其中 **`944` 个**可从 `Read(/reference-0.png)` 回包解码出 944 张唯一参考图，**`184` 个**为纯文本）；但现有导出脚本尚未把这 944 张图落盘，且对方四榜去污染不覆盖我方 `devtest-v2 / Aodi / img23d`。
3. **CAD 与 2D 分类树采用“36 叶全量词表 + 12 个 Phase 1 核心采样族”双层结构**：主提案的 36 叶保留作需求索引与多标签词表，但首批百条级预算若直接均摊 36 叶 × 4 任务形态每格仅 2–4 条；修订为**首批各聚焦 12 个可证伪核心族（每族 ≥8 个独立训练题）**，将高风险/超纲叶（如 CAD Sweep 弯头与双件齿条啮合、2D 多骨骼步态与双摆）显式降级到 Phase 2。
4. **提前“小规模三轨干扰探针”并先核清真实单价**：不在未测成本前一口气批首周 300–500 条或 Phase B 千条精造；额度恢复后**第一笔钱先跑 1 个完整任务（≤4 次拿 2 条合格、导出 1 条 ≤172K 带 EOS 样本）摸清真实单价** → 每轨 10 题成本哨兵 → 在千条放量前提前做小规模三轨联训探针（对照同曝光单轨）排查跨轨工具/契约串扰。
5. **纠正多处口径与工期乐观假设**：
   - 更新 `9B-3DCF-Mix` 最终 30 题成绩：`20/30 (66.7%) → 7/30 (23.3%)` 内联、`5/30 → 0/30` 硬检查、`7/30 (23.3%) → 11/30 (36.7%)` 超时（主提案 23.1%/38.5% 为 26 题中途快照）；
   - 核实 CAD `render_glb_multiview.mjs` 与 `test_cad_pipeline.py` 已有 `flatShading`、`Z_range` 与路径测试，先验现行代码导出勿重复造轮子；
   - 放弃“2D 复用 `threejs_rubric_synth.py` 80% 代码”的工期估计——Canvas 与 SVG 验证机理差异大，必须先交 Canvas + SVG 正反例反例包再排工期；
   - 修正五本账算术：按实际有效监督 `U` 精确锁定 `45 / 18 / 17 / 7 / 13 = 100% U`（CAD 9 条通过轨迹真实均 `U` 仅 `5,753`，不是序列长度 `18,163`），不靠“1,000 条 ≈ 40 条小红书”的混口径估算预算。

## 三、定型方案核心规格（融合修订版）

### 3.1 三轨交付物与能力边界（4 字段显式解耦）

所有任务卡在 `manifest` 与评测报告中必须显式记录四个独立布尔/枚举字段，杜绝“离线”或“动画”口径含糊：
- `needs_http_server`（`false` = 纯 `file://` 直接打开；`true` = 需本地 HTTP）
- `bundle_mode`（`single_file_inline` vs `multi_file_local`；允许源码目录多文件 + 运行交付单文件）
- `allow_network`（三轨均 `false`）
- `motion_type`（`continuous_deterministic` / `interactive_state_switch` / `static_geometry`）

| 赛道 | 主引擎与交付物 | 我方独有护城河 & 验收重点 | 明确不越界的红线 |
| --- | --- | --- | --- |
| **Track 1 · 3D 动画** | Three.js r180；离线单文件 `output/index.html` + 可编辑 `output/src/` | 吸收小红书 L1 方法 + L2 高审美场景种子，叠加确定性连续 3D 运动（`window.renderAt(t)`）、纯 WebGL 帧差防假动、`repair/healthy` 止损与 `Eval v3` 盲评 | L3 原始多文件暂为 `0%`；L4 Blender 为 `0%`；纯切镜头/切灯（M06）不冒充刚体运动 |
| **Track 2 · 3D 建模打印（CAD）** | CadQuery 2.6.1；参数化 Python + STL / 3MF / GLB 三格式回读 | 确定性四层几何金字塔（AST 沙盒 → 水密 2-流形 & 连通体 → 包络/体积/孔轴探针/参数回归差分/真值 Voxel IoU → `flatShading + Z_range` 4 视角）+ **BenchCAD 25 题纯净 OOD 尺子** | `OpenSCAD = N/A`；不作切片/实物打印/材料强度/实体装配公差认证；外观摆件打印单标 `unverified` |
| **Track 3 · 2D 动画** | Canvas 2D（主）+ SVG（辅）；离线单文件 HTML + `window.renderAt(t)` + `#play/#pause/#scrub` | 冻结字体/DPR/时钟 + 屏蔽 HUD 比较主体 ROI；Canvas 查清屏残影/伪随机/逆序 seek；SVG 查 DOM/transform/viewBox/裁切/CSS·SMIL 时钟一致性；周期题验接缝前后位置+速度 | 物理/算法/数据题严禁拿文生图静帧当数值真值；Canvas 与 SVG 独立校验、独立基线 |

### 3.2 两棵修订版分类树（36 叶全量词表 + 12 个 Phase 1 核心采样族）

> **统一记账纪律**：每题挂 **1 个主采样族（用于配额与 split 隔离）** + **多个平权叶标签（用于覆盖检索）** + **1 个任务形态（`build / repair / edit / healthy`）** + **特征/故障操作标签**；题目与其 Reverse-Fix 坏例、翻译、近邻参考图绑定同一祖先，整体隔离 train/dev/test。

#### A. CAD 建模打印树（`CadQuery-Tree v1.1`：36 叶索引 → 12 个 Phase 1 核心采样族）
1. **支架与法兰座**（`C01L01–03`）：孔距、筋朝向、局部改孔的非目标不变区
2. **夹持挂架与管夹**（`C01L04`, `C04L01`）：定向攻克 XZ/XY 轴向错位反例，探针测通道轴线
3. **盒盖与壳体接口**（`C02L01/03/04`）：定向攻克下伸内唇反向、侧孔、定位销与配合间隙（弹性卡入延后）
4. **通风面板与翅片**（`C02L02`, `C07L01/04`）：限排数防 OCCT 拆面爆炸，测贯通、壁厚与孔间距
5. **单轮与轮毂**（`C03L01/03`, `C04L03`）：先攻轮毂/键槽/轮缘/疏筋（真渐开线齿形、链轮、密滚花延后）
6. **紧固小件与维修替换件**（`C04L05` + 补衬套/轴套/替换把手旋钮）：给定接口尺寸改配
7. **导轨与止挡**（`C05L01/02`）：验截面配合间隙、止挡位置与行程采样
8. **钻孔治具**（`C05L03/04`）：给孔型图与基准面，测钻模板轴线与非目标面
9. **法兰与直通转接**（`C06L01/02` + 补异孔距转接板/异径接头）：测法兰厚度与通孔连续性
10. **收纳盒与工具插架**（`C08L01/02`）：测隔板实体与插槽盲孔深度
11. **桌面底座与倾角外壳**（`C08L03`, `C02L05`）：数字稳定支撑面、设备净空与插线方向
12. **线轴与理线件**（`C08L04` + 补线缆穿槽/桌缘导线座）：过线通道探针检验

- **Phase 2 / 降级叶**：`C01L05` 可调角度支架、`C03L02` 齿轮齿条啮合、`C03L04/05` 复杂凸轮/万向节、`C04L02` 弹性卡扣（只验几何不声称弹性）、`C04L04` 多件铰链、`C06L03` Sweep 弯头（先做相交通孔 T 块再进 Sweep）、`C06L04` 复杂喷嘴（先回转漏斗）、`C07L02/03` 稠密针翅与曲面导风罩。不把“>50 面自动判失败”当生产硬断言，改为按面数 + 特征操作数 + 件数联合分桶统计。

#### B. 2D 动画树（`Anim2D-Tree v1.1`：36 叶索引 → 12 个 Phase 1 核心采样族）
1. **摆与振子**（`A01L01/02`，单摆/弹簧先上、双摆延后）：相位、杆长、阻尼包络

6. **几何构造与证明**（`A04L01/04`）：圆周描迹、相似三角形、辅助线与角度可验证

8. **钟表与节律**（`A05L01–03`）：离线节拍、刻度与对称形变，按周期测接缝前后位置+速度
9. **视差插画**（`A06L01–04` 合并为主题变体）：三层相对速率、主体遮挡与镜头连续性（可做有/无风格参考图 A/B）
10. **矢量生长与标识动效**（`A07L02` + 补 Logo 描边/标题字幕出入场，SVG 主场）：路径长度、字距、裁切与一次性终态
11. **UI 状态过渡**（`A07L03` + 补按钮反馈/加载到成功失败/卡片展开）：触发、暂停与中断后恢复
12. **交互教学**（`A08L03/04`）：解析轨道或单参数控件，固定变更时刻核对像素与数值

- **Phase 2 / 降级叶**：`A02L02` 光栅干涉、`A02L04` 复杂电磁场线、`A03L04` 并入视差、`A03L05` 大规模鱼群/鸟群、`A04L02/05` 深层分形与易破随机 seek 的逐帧细胞自动机、`A05L04` 复杂视错觉、`A07L01` 多骨骼步态（先两节肢体测脚滑）、`A08L02` 复杂仿真电路。
