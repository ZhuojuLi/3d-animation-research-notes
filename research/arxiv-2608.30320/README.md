## 1. 三大核心架构组件：`GDN + QSA + Gated Residual`（§2）

### 1.1 `3:1` 混合线性-稀疏注意力：`GDN` + `QSA`（§2.1）
网络按 **`3 层 Gated DeltaNet (GDN) : 1 层 Qwen Sparse Attention (QSA)`** 周期交错构建百万级上下文主干：
1. **`GDN` 线性注意力块（稳定有界门控 + `FlashQLA`）**：
   - Query/Key 经过因果 `ShortConv` 与 L2 归一化后进入 Delta 规则状态更新；输出端采用**有界 Sigmoid 门控 + Zero-Centered RMSNorm（零中心化均方根归一化）**，从源头阻断深层状态范数漂移。
   - 自研 TileLang 算子 **`FlashQLA`** 实现前向 **`2×–3×`**、反向 **`2×`** 算子级提速。
2. **`QSA`（Qwen Sparse Attention，256K 持续预训练两阶段无损切入）**：
   - **关键降维设计（先池化、再加部分 RoPE）**：轻量 4 头 MQA Indexer 先沿序列维按比率 $r=4$ 对 Key 做均值池化（`AvgPool`），**在压缩后的块级表示上再施加 64 维 Partial RoPE（`PRoPE`）**，将索引打分复杂度压降至 $O(n^2 / r)$；选取 $K=2048$ tokens（对应 $K_B = 512$ 个块）。
   - **两阶段平滑稀疏化（在 256K CPT 阶段引入）**：
     - *Stage 1（Index Warmup，1,000 步 / 2B tokens，LR `1e-3`）*：冻结主干，仅训 Indexer 去拟合全注意力权重的块级 `MaxPool` 分布（KL 蒸馏）；
     - *Stage 2（Sparse Joint Training，8,000 步 / 200B tokens，LR `2.5e-5`）*：全参数解冻，在 Top-$K_B$ 稀疏掩码下端到端联合微调。
   - **实测收益**：在 **1M 上下文**处实现 **Prefill `7.6×` 提速、Decode `4.9×` 提速**，且长程大海捞针与多针推理反而**超越全注意力基线**（`RULER 512K–1M`: `90.08 -> 93.00`，`MRCR 1M`: `20.71 -> 26.44`）；配合 MTP 投机解码直接复用主步选出的 Top-$k$ 稀疏块索引，平均接受长度高达 **`4.07`**！

### 1.2 门控多分支残差 `Gated Residual (GR)`（§2.2, Eqs. 30–34, Fig. 7）
针对 `mHC` 仍需执行 Sinkhorn-Knopp 双随机迭代及维护跨流混合矩阵 $H_{\text{res}}$ 的开销，Qwen3.8-Next 提出更简洁且后训练更稳健的 **`Gated Residual (GR)`**（默认分支数 $n_r = 4$）：
- **彻底移除 $H_{\text{res}}$ 与传统 Pre-Norm**：维护 4 条并行残差流 $\bm{R}^{(l)} \in \mathbb{R}^{4 \times d}$，每层先对各分支做独立 Group RMSNorm，随后通过低秩瓶颈（秩 $r = d/8$）生成**逐元素 Sigmoid 读取门 $\bm{G}^{(l)} \in (0,1)^{4 \times d}$** 加权求和送入 Attention/FFN 子层；子层输出再经由 4 个**标量写回门 $2\sigma(\bm{w}^{(l)}) \in (0,2)^4$** 累加回 4 条残差分支：
  $$\bm{x}_{\text{in}}^{(l)} = \sum_{k=1}^{n_r} \bm{G}_{k}^{(l)} \odot \mathrm{RMSNorm}\!\big(\bm{R}_{k}^{(l-1)}\big), \qquad \bm{R}_{k}^{(l)} = \bm{R}_{k}^{(l-1)} + 2\sigma(w_k^{(l)}) \cdot \bm{y}_{\text{sub}}^{(l)}$$
- **FP8 残差存储与自动路径分工（Fig. 7）**：归一化与有界门控使 4 分支残差流可直接以 **FP8 精度驻留显存**而无损精度；路径长度分解实验揭示：**4 条分支自发涌现出“1 长 + 3 短”的清晰拓扑分工**——其中 1 条分支专门承担跨层远距高速干道（平均跨度 **`10.9` 层**，将 Layer 0 词法特征直连投送至中后部全局 QSA 注意力枢纽层），其余 3 条分支专注局部细粒度特征传递（平均跨度 **`3.4–3.9` 层**）。

### 1.3 第 2 层主机内存异步预取 `51B` N-gram Embedding（§2.3）
- 在第 2 层注入规模达 `51B` 参数的多元 N-gram 嵌入表；由于每步输入 token 的 N-gram 哈希索引在进入第 0 层前即完全已知，训练与推理时**将整张 `51B` 表常驻于廉价 CPU 主机内存（Off-Accelerator Host DRAM）**，与前两层 GPU 计算做异步 PCIe 预取重叠，实现**零 GPU 显存驻留成本与零吞吐损耗**的知识容量扩容。

## 2. 拆分正交化 `Muon`、省去 `18.8%` 步数的无 Warmup 定律与 `4× LR` 极限压测（§3）

### 2.1 按头/按门拆分正交化 `Muon` 与 `Canzona` 调度（§3.1）
- 采用 **8 步 Polar Express 极小极大最优 Newton-Schulz 迭代**（RMS 缩放因子 $0.2\sqrt{\max(A,B)}$，动量 $\mu=0.95$，$\epsilon=10^{-14}$）。
- **拆分正交化铁律（Split Orthogonalization）**：Megatron-LM 默认将多头 `QKV`、`GDN` 多路投影以及 SwiGLU 的 `gate/up`（`fc1`）拼成巨型融合矩阵；若对融合大矩阵直接做正交化，会跨注意力头、跨门控通道混杂奇异谱。Qwen3.8-Next **强制在正交化前按每个独立 Attention/GDN Head 以及独立 `gate` / `up` 矩阵切分开分别做 NS 正交化**（Embedding、LM Head、MoE Router、`GR` 低秩门投影与标量门仍保持 AdamW）。
- 为消除切分后数百个小矩阵 NS 内核的分布式负载失衡与 Launch 开销，设计了 **`Canzona` $\alpha$-均衡 NS 算力划分器 + 全流程 CUDA Graph 捕获**。

### 2.2 Scaling Law 重标定与“无需 Batch-Size Warmup”硬结论（§3.2）
1. **最优批大小与最优学习率双双上移**：相比 AdamW，拆分 `Muon` 将同规模模型的最优全局 Batch Size 翻倍推高（`12.6M -> 25.2M` tokens，Loss 额外下降 `-0.0072`），并将最优峰值学习率推高 **`2.6×`**（`6.8e-4 -> 1.76e-3`，在 `156B-A7B` 对照实验上令下游基准均分暴涨 **`+4.14` 分**）。
2. **彻底废除 Batch-Size Warmup（直接省下 `18.8%` 优化步数！）**：
   - 传统大模型预训练惯例在前期从小 Batch 逐步线性爬升至大 Batch（BS Warmup），导致在相同总训练 Token 预算下必须多跑大量小 Batch 通信同步步。
   - 严格受控实验证明：在 `Muon + GR` 体系下，**开启 Batch-Size Warmup 不仅多消耗了 `18.8%` 的总优化器更新步数（Wall-clock 通信与调度成本大增），其最终收敛 Loss 反而比从第 1 步直接满血跑最大 Batch Size 差 `2.5e-4 ~ 3.5e-4`**！因此生产级训练直接采用 **Zero BS Warmup**。

### 2.3 `2× / 4×` 峰值学习率无衰减极限稳定性压测（§3.3）
在 28 层 `25B-A3B` MoE 上不加任何学习率衰减（Constant High LR），直接轰击 `2×`、`3×`、`4×` 标准峰值学习率：

| 极限压测条件（全程无 QK-Clip / 无 SwiGLU-Clip） | AdamW 基准架构 | **Muon + Gated Residual (`GR`)** | 物理机制解析 |
| :--- | :---: | :---: | :--- |
| **`2×` LR 每万步 Loss 尖峰数** | `4.3` 次 / 10k 步 | **`0.2` 次 / 10k 步** | 正交化更新天然约束权重谱范数步长 |
| **`4×` LR 每万步 Loss 尖峰数** | **`183` 次 / 10k 步** | **`0` 次 / 10k 步** | **零 Loss 尖峰！** |
| **`4×` LR 触发梯度裁剪（`>0.5`）步数** | `213 / 19,932` 步 | **`0 / 19,932` 步** | **全程零次触碰梯度裁剪线！** |
| **固定 AdamW `3×` LR 下开启 `GatedNorm` 消融** | `32.0` 尖峰/10k（`256` 次越界） | **`3.2` 尖峰/10k（`20` 次越界）** | 显式乘法门控替代靠激活离群值（Outliers）调节幅度 |
| **生产全量跑（276B 窗口统计）$p_{99.9}$ 梯度范数** | `0.298` | **`0.066`（降低 `4.2×`）** | 梯度范数标准差同步降低 **`4.3×–4.7×`** |

## 3. 四大“预训练 Loss 与后训练/下游严重背离”经典案例（全篇精髓！）

本文最重要的工程贡献之一，是用真金白银的后训练与下游评测推翻了“只看预训练 Validation Loss 选架构”的盲区：

1. **背离案例 1：全局注意力层 `NoPE` vs `RoPE`——预训练 Loss 完全持平，后训练出现严重“无限生成停不下来”（§2.1.1）**
   - 在 `3:1` 混合架构（GDN 已自带局部因果位置偏置）中，将全局注意力层的部分 RoPE 去掉改为 `NoPE`，**预训练验证集 Loss 曲线几乎严丝合缝毫无差别**。
   - 然而一旦进入 SFT 与 RL 后训练长文本生成阶段，**`NoPE` 变体出现了显著更高比例的 Endless Generation（无法正常生成 `<|im_end|>` 终止符、陷入循环复读直至打爆上下文上限）**！根源在于缺少显式高频相对相位锚点使长程生成丧失全局进度感。因此最终坚定保留 64 维 `PRoPE`。
2. **背离案例 2：`Gated Residual` 稀疏分支读写（Top-2 Sparse GR）——预训练无损，后训练明显退化（§2.2）**
   - 若将 $n_r=4$ 分支的稠密 Sigmoid 读写门改为每次只激活 Top-2 分支（稀疏读写），预训练 Loss 与 Base 评测几乎零掉点；**但经过指令微调与思维链 RL 后，稀疏分支切换引发的路由不连续性使后训练表现显著劣化**。最终锁定全稠密 4 分支 `GR`。
3. **背离案例 3：动态门控 `GR/mHC` vs 静态固定权重残差——Loss 仅差 `0.002`，下游基准暴涨 `+1.98` 分（§2.2, Table 5）**
   - 从静态跨流残差升级为输入依赖的动态门控（`mHC` / `GR`），预训练 Loss 仅从 `1.596` 微降至 `1.594`（`-0.002`，在常规实验噪声边缘）；但 14 项下游推理与编程基准均分却从 **`52.49` 跃升至 `54.47`（`mHC`）/ `54.66`（`GR`）**，证明动态路由改变的是高阶多步组合表征质量而非浅层双元词频预测。
4. **背离案例 4：N-gram 词表从 `20V` 扩至 `200V`——Loss 单调狂降，英文与 STEM 推理早已饱和（§2.3.2, Tables 8–9）**
   - 将主机内存 N-gram 表容量从 `20×` 词表放大到 `200×` 词表，预训练 Loss 从 `1.585` 一路单调下降至 `1.526`；但拆解下游任务发现：**英文理解、代码与数学 STEM 基准在 `20×–50×` 处早已完全饱和**，后续 Loss 下降几乎全部被中文长尾百科记忆（C-Eval / CMMLU）吸收——警示切勿被记忆型表面困惑度下降误导算力分配。

## 5. 对本项目的工程映射（`Qwen3.8-27B` 后训练与 RL 调优指南）

1. **稠密 `Qwen3.8-27B` 天然免疫 MoE 专家路由与稀疏 Indexer 非确定性坍缩**：
   - 相比 `GLM-5`（DSA Top-$k$ 非确定性崩溃）与 `DeepSeek-V4` / `Kimi K3`（MoE 训推专家路由漂移需 `R3`/`IcePop` 抢救），我们选定稠密 `Qwen3.8-27B` 在 `2×8 H800` 上跑 `GSPO-token` / `SAPO` 具有**极高的训推数值一致性与梯度稳定性优势**（继承了 Qwen3.8 家族极低的 $p_{99.9}$ 梯度离群特性）。
2. **SFT / RL 严禁只看 Token NLL Loss，必须把“无限生成率（Non-Termination Rate）”列为一等监控指标**：
   - 谨记本文 §2.1.1 教训：验证集 Loss 极低的模型在超长多轮后训练后仍可能出现无法终止的复读坍缩。在清洗小红书 `3DCodeFactory` 长轨迹（`DeepSeek-V4.1-Flash-1017` 合成，99.9% 含超长上下文压缩）做 Stage 0 SFT 时，**必须过滤未正常闭合工具标签或被截断未收敛的残缺尾部**，并在 RL 阶段实时监控 `EOS` 正常终止率。
3. **长上下文训练直接省去 Batch-Size Warmup，把宝贵 H800 步数预算全额投入有效大 Batch 更新**：
   - 遵循 §3.2 实证结论，在 Stage 0 SFT 与 Stage 2 RL 中无需设置小 Batch 爬坡阶段，直接按目标有效全局 Batch Size 启动更新，节省近 `15%–19%` 同步开销。
