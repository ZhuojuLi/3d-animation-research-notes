# 分层抽样方案审稿意见

> 公开整理版 · 2026-11-25。保留成文时点的记录；计划、文献结果和本地实测请分别理解。 环境路径已泛化，未收录的附件已标注；发布范围见 [整理说明](../../PROVENANCE.md)。

## 事实（据已完成统计）
- N=10697：A 3933 / B 3263 / GLB 3501；原文及规范化精确重复为0。
- GLB同标题267组共1178条（占GLB约34%），为配置变体。
- A复杂度1–10、B 1–8，均为课程标注；GLB无。题面中位数37 vs 265/283。
- GLB“已验证”为发布方自述；A/B本地仅查少量。三源依赖契约不同。

## 1. 统计盲点
- 近重复未测：精确重复为0不排除模板化、仅改参数的近重复；需n-gram/结构相似度检查。
- 层格稀疏：领域×复杂度×长度可达上千格，多数格<5条；须预先写定合并规则。
- 复杂度跨源不可比，GLB缺失：只能源内分层，不能当统一变量。
- 长度与来源共线：GLB几乎全在短桶，跨源长度分桶≈来源分层；应源内分位数分桶。
- 依赖/版本契约未纳入分层，而运行失败可能主要由环境决定。
- 标注一致性未知；误标会使分层失效。
- 结构异常全量复核样本与随机样本须分开估计，不能合并算通过率。

## 2. 同标题变体
建议：降权，不硬去重，也不等权全保留。完整集保留全部；核心集以标题组为一级抽样单元（簇），组内再随机抽1–k条，或权重取1/√m。方差按簇计算。硬去重会丢配置覆盖，等权会让少数物体占GLB三分之一概率。

## 3. 分层随机运行审计
- 每源独立预算；源内每领域保底n_min（不足则全取），余量按Neyman分配，失败方差未知时按p=0.5。
- 高复杂度层有意过采样，记录包含概率π，总体失败率用1/π加权，同时报告分层未加权结果。
- 小层用Clopper-Pearson区间；0/n时报告上界（约3/n）。
- 固定随机种子、预注册分配表；锁定各源依赖版本，“环境失败”与“内容失败”分开记录。

## 4. 三方比较（抽象设计）
- 臂：完整池F、同规模随机核心R、分层核心S（|R|=|S|=n）。
- 固定总预算B（总处理/检查次数）。F每条约曝光B/N次，R、S约B/n次；记录每个ID的曝光次数、层、簇，报告唯一条目数、最大重复次数、各层曝光分布。
- 加对照臂：F中按B无放回抽取（单次曝光），用以分离“多样性”与“重复曝光”效应；另可让S在不同预算下重复，看数量效应。
- R取≥5个种子形成分布，S与该分布比较，不与单次R比较。
- 指标：非空层比例、层边际分布与F的总变差距离、固定独立检查集上的覆盖结果；主指标与停止规则预注册。

## 5. 当前证据不能支持
- “全部示例可运行/渲染正确”（A/B仅抽查，GLB为自述）。
- “无重复”——仅限精确与规范化层面。
- 复杂度标注与实际失败率相关；GLB短题面即简单。
- 跨源复杂度可比；领域标签准确。
- 分层核心优于随机核心（尚未比较）。
