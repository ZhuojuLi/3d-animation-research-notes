# 三轨交互式视觉项目：验收范围与统计口径评审

> 公开整理版 · 2026-11-25。保留成文时点的记录；计划、文献结果和本地实测请分别理解。 环境路径已泛化，未收录的附件已标注；发布范围见 [整理说明](../../PROVENANCE.md)。

标注：【事实】只依据题述资产；【推断】是审稿人的判断；【建议】是可执行的动作。本次未读取任何代码或数据。

## 1 总体判断
- 【事实】3D 动画已有首版和 60 题配对评测，但快照与完整请求还有缺口。3D 打印只有 V1 和 2 个单次 smoke，正式导出仅支持 CadQuery。2D 动画既没有项目，也没有评测集。
- 【推断】三轨的成熟度依次是“可评测”“可演示”“未开建”，目前都不满足汇总条件。
- 【建议】主表只报三轨各自的 Accepted@1。2D 一栏填“N/A（无题集）”，不能填 0，也不能省略这一栏。

## 2 Accepted@1 定义与汇总门槛
**共享定义**：一个 episode 对应一次独立的任务输入。它从空工作区开始，由 Agent 自主完成全流程，期间不能有人工编辑、提示，也不能挑选重试结果。最终产物交给独立验收器判定（不能复用 Agent 自检），所有必要项都通过才算 Accepted。缺证据、超时、崩溃或人工接管都算失败，并计入分母。
**按轨独立**：必要验收项、证据格式、题集版本。
**防止等权掩盖退化**：主表三轨并列，每轨附 n、95% CI 和相对上一 checkpoint 的配对差值。任一轨出现显著回退（比如下降 5pp 以上）就阻断发布，不允许用其他轨的提升抵消。等权汇总只作为组内二级指标，并注明有哪些轨参与。
**汇总门槛（须全部满足）**：①每轨有冻结题集（≥60 题）和配对基线；②验收器与人工抽检的一致率 ≥90%；③连续两个 checkpoint 的结果可复现；④请求和快照的完整率达到 100%。【推断】3D 动画缺④，打印缺①②，2D 四项全缺。

## 3 验证器边界
- **可共享**：episode runner、人工接管审计、日志/截图/哈希归档、断网检查、无头浏览器加载与控制台报错检查、统计脚本。
- **必须按轨独立**：
  - 3D：机构约束误差、关键时刻截图、交互响应。
  - 打印：单实体与水密/流形、尺寸公差、最小壁厚、导出回读一致性。
  - 2D：时间编排、播放/暂停/拖动后的状态一致性、循环无跳变、关键帧位置与缓动。
- **打印的声明边界**【建议】：只能声称“数字几何满足参数规格，且可以导出”。不能声称可切片、可打印，也不能声称材料、强度或实物公差合格。OpenSCAD、OS 沙箱和 WebGL 验收形成之前，不进入 Accepted@1 口径。
- **2D 最小开建资产**【建议】：任务规格模板；≥20 题种子题集；可注入的确定性时钟；关键帧参考状态；Playwright 交互脚本；≥10 题人工标注，用于校准验收器。

## 4 最小端到端 smoke
每轨都走同一流程：初版→执行→日志/截图→修改→重建→新证据→交付→独立验收。
- **3D**（离线连杆机构，可点击暂停/恢复）
  - 断网加载，控制台无错误。
  - t=0/1/2s 三张截图能看出运动，约束误差低于阈值。
  - 暂停后连续两帧一致。
  - 修改转速后，新截图能体现周期变化。
- **打印**（带 M3 孔的支架，壁厚 ≥2mm）
  - CadQuery 执行成功，产物为单实体且水密。
  - 尺寸误差 ≤0.1mm，实测最小壁厚 ≥2mm。
  - 改参数重建后，尺寸随之变化。
  - GLB/3MF 回读后体积误差 <1%。
- **2D**（2s 循环的弹跳球）
  - 在注入时钟下，关键帧位置误差 ≤2px。
  - 暂停后画面冻结。
  - 拖动到 t 的画面，与直接渲染 t 时刻一致。
  - 循环边界没有跳变。
  - 修改缓动后，新证据能体现变化。

**失败停止规则**：
- 证据哈希没有更新，即判失败。
- 同一错误连续出现 2 轮，停止。
- 超出时间或预算，停止。
- 需要人工输入，停止并记为“接管”。
- 验收器无法运行，该轮作废，不能记为通过。

## 5 P0/P1 测试资产（8 项）
1. P0：冻结的版本化题集和配对基线。3D 补齐快照与完整请求，打印扩充到 ≥30 题。
2. P0：完整审计日志，包含请求、工具调用和产物哈希。
3. P0：独立验收器，以及人工抽检一致率报告。
4. P0：重复稳定性测试。每题跑 ≥3 个种子，报告 pass^k；单次成功不算稳定。
5. P0：负例集，包括断网失败、非流形、壁厚不足、拖动错位等，验证器必须全部拒绝。
6. P1：2D 种子题集和确定性时钟框架。
7. P1：打印导出回读一致性检查，以及 OpenSCAD 对照。
8. P1：按轨的回退看板，展示配对差值、CI 和阻断阈值。

**说明**：文件存在、页面能打开、单次 smoke 通过，都只能算“可运行”证据，不等于 Accepted。
