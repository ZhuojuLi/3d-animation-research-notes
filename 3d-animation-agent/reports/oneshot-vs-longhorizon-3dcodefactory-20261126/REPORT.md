## 一、一句话核心发现

**小红书 Dots Studio（`3DCodeFactory`, `arXiv:2611.28783v1`）** 使用了与本项目几乎 1:1 相同的技术栈——教师 **`DeepSeek-V4.1-Flash-1017`** + 脚手架 **`Claude Code v2.1.251`** + 基座 **`Qwen3.8-27B` / `Qwen3.5-9B`**，并用三组硬实验证明：

1. **203 万条单轮静态数据救不了 27B**：在 `Qwen3.8-27B` 上喂入开源最大的 **203 万条单轮数据 `3DCodeVerse`（4.66B tokens）**，三榜均分仅 **`+0.12`**（`58.66 → 58.78`），Three.js `P3D-Bench` 反而**倒退 `-0.63`**；而喂入 `3DCodeFactory` 仅 **5,045 条**长程多轮视觉闭环轨迹，三榜均分暴涨 **`+8.12`**（`58.66 → 66.78`），**全面反超同系 2.4T 旗舰 `Qwen3.8-Max`（`62.75`）**。
2. **同一批 5,045 题，去掉多轮过程直接丢掉 `11.75` 分**：只取这 5,045 题的 `输入 → 最终代码`（Single-Turn Pairs）训 27B，BlenderWorld 仅涨 `+5.36`（`53.02 → 58.38`）；保留完整多轮写代码→渲染→看图→纠错轨迹后，分数飙至 **`70.13`（`+17.11`）**——**多轮长程交互过程本身独占 `+11.75` 分**。
3. **长程不等于“瞎堆轮数”，Rubric 过滤 + 轮级坏轮掩码决定精细度上限**：未经过滤的长程轨迹虽然把中位轮数推得更长（`178` 轮 / `412.5K` tok），但工具报错率高出 **81%**（`7.8% vs 4.3%`）、连续重复无效编辑暴增 **2.7×**（`18.6% vs 6.8%`），精细度（Dimension）比过滤版低 **`-8.38` 分**。

## 三、小红书 `3DCodeFactory` 完整训练策略拆解

### 1. 数据生产与采样策略
- **视觉锚定 + 分类树对齐（P01–P07）**：从 DiffusionDB / Wikipedia / Amazon 混合文本映射到 10 大域 56 叶节点，先由文生图生成 3D 参考图 $I$ 锚定空间布局与材质，再合成需求 $(C,S,F)$ 与对编码 Agent 严格隐藏的三维评分细则 $\mathcal{R}=(R_{\text{vis}}, R_{\text{spec}}, R_{\text{func}})$，并由 **`P07` 出题审计**保证零隐藏考纲。
- **隐去参考图构造纯文本变体**：虽然出题用 $I$ 锚定细节，但在采样与训练阶段按比例构造纯文本无图任务（覆蓋中英双语 + 专业/普通人设），实现纯文本与图文跨模态共同暴涨。
- **高预算长程采样**：`DeepSeek-V4.1-Flash-1017` + `Claude Code v2.1.251` + 离线隔离 Docker 沙盒，窗口 `384K`、单轮上限 `128K`、`T=1.0, top_p=1.0`、`N_max=6`。
- **100% 保留原生简短 CoT**：HF 实查确认全部保留 DeepSeek 原始第一人称电报式 `reasoning_content`，不做二次摘要改写。

### 2. 三阶段漏斗 + 几何校准 + Best-of-2（Table S4 & Table S5）
- 初始 `5,283` 题 / `13,312` 条完成 rollout（综合均分 `0.670`）：
  1. **Stage 1 单维硬底线（任一适用维 `< 0.50` 淘汰）**：淘汰 `2,389` 条（`17.9%`），均分升至 `0.733`；
  2. **Stage 2 均分底线（`< 0.60` 或未凑齐 2 条淘汰）**：淘汰 `833` 条（`6.3%`，含 `238` 道未凑对题），留 `10,090` 条配对池（均分 `0.747`）；
  3. **Stage 3 Best-of-2**：每题两选一取高分赢家，最终 `5,045` 条（留存 `37.9%`），均分达 **`0.791`（`+0.121`）**。
- **几何难度校准**：对 $d_{\text{geo}}\in\{1..5\}$ 施加偏移 $\Delta=\{0.000, 0.006, 0.022, 0.052, 0.060\}$，150 题三专家双盲验证缺陷拦截 Precision **`74.1% → 87.2%`（`+13.1pp`）**，Recall 保持 `91.1%`，GSB 人类一致率 `77.3%`。

### 3. 轨迹切分、轮级坏轮掩码与 SFT 超参（Table S3 & `trajectory.py`）
- **Compaction 边界切分**：在 Claude Code `compact_boundary` 或 `393,216`（384K）处切段（5,045 轨迹 → 6,414 段），续段开头的压缩摘要标 `loss_mask=True`。
- **轮级异常 Loss Masking（“掩坏轮、保纠错轮”）**：仅对触发 5 类异常的**单条 assistant 轮**屏蔽梯度（`tool_execution_error`、`protocol_leakage`、`repetitive_reasoning_loop`、`duplicate_tool_target`、`abnormal_ending`），同时保留上下文，让紧随其后的诊断与自修复轮参与训练。
- **训练超参**：Full-Parameter Multimodal Interleaved SFT、YaRN 1.5× 扩窗至 **`384K`**、**严格 `1 epoch`**（765 steps）、`Global Batch Size = 48`、`Peak LR = 1.0e-5`（Cosine Decay + `3%` linear warmup）、`AdamW (β1=0.9, β2=0.95, wd=0.1)`、`BF16`、`max_grad_norm = 1.0`。
