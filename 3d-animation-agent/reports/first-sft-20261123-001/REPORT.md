## 训练配置与运行

- 使用 gpu34 和 gpu38 的 16 张 H800。两台机器沿用团队固定 Swift/Megatron 镜像，TP=4、PP=4、CP=1、DP=1，启用序列并行、逐层重计算和 Transformer Engine 融合交叉熵。
- 长度上限 180,224，训练样本最长 171,524。micro batch 与 global batch 均为 1。所有样本以完整长度参加训练，一轮 10,946 步。thinking、正文和工具调用的权重分别为 0.5、1、2。
- 正式训练采用 Adam、峰值学习率 1e-6、余弦衰减至 1e-7，warmup 328 步。在第 32 步及每 500 步写出含模型、优化器与 RNG 的恢复检查点，保留最近三个；最后用 812 条代码验证数据计算 loss。正式模型输出为 Megatron 分片检查点。
- 本机独立服务检查 smoke 的实际优化器更新、真实批次和检查点，再启动两台训练机。正式全程的阶段、训练指标和可恢复检查点持续写入实时状态。若训练进程带有明确的临时连接错误退出，监督程序可从已提交的检查点有限次恢复。训练启动器（本地附件未发布） · 监督程序（本地附件未发布）
