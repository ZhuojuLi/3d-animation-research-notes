# 首版 3D Agent 配对评测

> 公开整理版 · 2026-11-25。保留成文时点的记录；计划、文献结果和本地实测请分别理解。 环境路径已泛化，未收录的附件已标注；发布范围见 [整理说明](../../../PROVENANCE.md)。

比较起点为 BF16 Qwen3.8-27B，学生为混合 SFT 第 10946 步。使用冻结 dev 的 6 个题族共 12 题，随后冻结执行协议，测 12 个新题族共 48 题。每题两臂各一次，生成、修复、局部编辑分别汇总。带参考图的 canary 单独报告。

每侧使用一台机器上的 4 张 H800、TP4、262144 上下文、同一客户端、medium 思考、200000 自动压缩窗口、每轮最多 8192 输出 token 和每题 3600 秒。每侧每批并行至多 12 题。工具为 Read、Write、Edit、Bash、Glob、Grep。每题有独立离线容器，除只读依赖与推理端点外，仅可访问当题工作区。两臂的服务标识由宿主核对，模型看到相同的请求名称。

Accepted@1 要求模型在时限内完成，可编辑源码和 HTML 齐全，单独冷加载自包含 HTML 成功，数值机制通过，实际可见几何满足逐题行为、可读性、交互定帧，以及修复或编辑题的保留要求。技术条件失败即不通过。对于自绘控制和随机像素的情况，由盲评检查实际交互及复现证据。盲评无法查证的结果单列，在全题分母中不算成功。基础设施故障单列并允许技术补跑，禁止根据质量重采样。先求族内均值，再对族等权。对题族配对抽样计算 95% bootstrap 区间。成本纳入全部尝试，缺失用量单列。

canary 的工具图像回执与独立冷加载快照见 canary-pass.json，图像输入的单题直接问答见 reference-probe.json。canary 使用设备 0–3，dev/test 使用两机各自设备 4–7；镜像、参数、权重、硬件型号相同，推理队列独立。数值正确 / 画面静止的评分校准见 grader-calibration.json，独立看图校准见 visual-calibration.json。

48 道 test 按每台实例 12 题排队。锁定后如两侧的备用 4 卡组均空闲且镜像、权重挂载和命令完全匹配，则每侧使用两个 TP4 实例并行处理两批；任一侧条件不满足时，两边都沿用一个实例。相同题目在两侧使用相同组号。实际调度写入 test-capacity.json，每次 trial 限时不变。

CLI 内嵌 system 文本使用项目兼容推理服务的映射拼入顶层 system，其他请求实体原样转发。dev 中旧服务已拒绝的 HTTP 400 单独归档，只有复核为该特定协议错误的 trial 可从原题面重新开始。正常结束与质量超时不重跑。test 两臂从开始即使用该兼容入口。
