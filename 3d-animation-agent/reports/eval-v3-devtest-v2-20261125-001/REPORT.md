## 一、核心真相：旧评测究竟扭曲了什么？

旧评测把“打包方式 / 超时 / API 细节”和“3D 动画作品质量”硬绑成一刀切二值 0/1，在两套题集上制造了**两种截然相反的严重失真**：

1. **在 `holdout-v1` test 48 上（旧报 `1/48 vs 3/48`）：旧尺子把 22 部通过视觉验收的真 3D 动画全按 0 分扔进了黑洞**  
   - 仅因同目录引用 `./bundle.js`，旧评分器杀掉了 **42 份可正常运行的动画**（其中 Base 27 份、Student 15 份），其中包括多部 **92–96 分的高质量 3D 动画**（如 `holdout-bulgarian-repair`、`holdout-galton-repair`、`holdout-analemma-*`、`holdout-dove-build`）。
   - 用 Eval v3 解耦补救后：**Base 真实视觉通过 `13/48 (27.1%)`、Student `11/48 (22.9%)`**；严格端到端干净交付依然严格对齐旧口径 **`1/48 vs 3/48`（零放水）**；而在**双方都成功出图的 22 对同题盲评对战中，首版 Student 反而以 `14 : 8`（63.6% 胜率）战胜 Base**（单评均分 `72.83` vs `70.67`），说明首版在较接近单场景分布的旧集上确实学到了一些画面/运动表现，但被缺 HTML/早停拉低了全集总分（`44.00` vs `48.58`）。
2. **在 `devtest-v2` 全 60 题上（旧技术通过报 `Base 12/60 vs Student 15/60`）：旧尺子反而“高估”了首版 `ckpt-10946`！**  
   - 题面写清“单文件内联”消掉 `./bundle.js` 噪声后，Eval v3 对全部 **85/120 份可渲染动画**（救回 **17 部**因 3600s 超时/同目录被旧尺子杀掉的视觉通过动画，最高达 **92 分**！）做了 100% 匿名五维评分 + 盲评对战，真实面目立刻水落石出：
   - **全集作品均分（0–100，不可渲染记 0）**：**Base `53.07` vs Student `42.93`**，题族配对 Bootstrap **Δ = `-12.39 分`（95% CI `[-22.56, -1.56]`，统计显著退化！）**
   - **视觉通过率（≥70 分 + 真 3D 运动 + 盲评 pass）**：**Base `18/60 (30.0%)` vs Student `11/60 (18.3%)`**（-11.7 pp）
   - **严格端到端干净通过（`E2E Clean Pass`）**：**Base `8/60 (13.3%)` vs Student `4/60 (6.7%)`**（旧 `technical_pass` 没看图就给 Student 算了 15/60，其中 11 条其实有画面/运动硬伤！）
   - **匿名盲评头对头对战**：全集 60 题 **Base `37` 胜 vs Student `15` 胜**（8 题双败）；双方均出图的 33 对正面交锋 **Base `24` 胜 vs Student `9` 胜（Base 72.7% 胜率）**！
   - **印证首版复盘**：首版 87.9% 无思考 Aodi + `tools=[]` + 0 真实修复不仅制造了 6/60 空答早停（导致可渲染率掉 11.7 pp），还实打实削弱了多轮复杂 3D 动画的运动准确度、任务保真度与修复能力（`repair` 视觉通过 `Base 6/18` vs `Student 3/18`）。

## 四、Round 2 训完后“一键即插即用”评测指令

Round 2 模型训完并在 `evals/devtest-v2` 跑出新臂产物（例如放在 `runs/<split>/<case_id>/round2/`）后，直接复用本框架即可在 ~5 分钟内出齐 **Base vs Round 1 vs Round 2** 完整四轨成绩单与匿名盲评胜率（支持断点续跑、零 GPU 占用）：

```bash
python3 ${WORKSPACE}/3d-animation-agent/scripts/eval_3d_v3.py \
  --cases ${WORKSPACE}/3d-animation-agent/evals/devtest-v2/cases.json \
  --split all \
  --runs-root <包含 base/student/round2 三臂的目录> \
  --arms base,student,round2 \
  --pairwise-arms base,round2 \
  --out-dir ${WORKSPACE}/3d-animation-agent/reports/eval-v3-round2-2026xxxx \
  --capture-workers 6 \
  --judge-workers 8 \
  --suite-name devtest-v2-round2
```

*注：如需同步对比 `round1 vs round2`，只需追加跑一次 `--pairwise-arms student,round2`（复用全部已落盘的 Layer 1 截图与 Layer 2 单评断点，仅补跑约 40 对匿名对战，耗时 < 2 分钟）。*
