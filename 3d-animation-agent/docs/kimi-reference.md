## 失败与修复记录

| 可见问题 | 原案例定位 | 修改与应吸收的经验 |
|---|---|---|
| 水面呈褐色网格 | 岩层顶面高于水面 | 改高度关系；不是泛用的“所有水面加固定数值” |
| 前缘、底部裁切 | 宽景相机没有包住完整岛体 | 调距离/目标高度，多时刻复验 |
| 甲板过黑、烟雾过淡 | 全景细节不可读 | 用截图调材质、透明度、尺寸与光照 |
| 拱圈穿过桥面 | 半圆拱与抛物线桥面不一致 | 修实际几何，不只看桥的轮廓 |
| `inspect.py` 破坏 Python import | 与标准库模块重名 | 检查脚本命名和错误归因 |
| 控件测试点不到按钮 | `?t=` 主动隐藏 UI | 区分捕获页与交互页 |
| CLI 截图超时 | 软件渲染/虚拟时间预算 | 持久 Playwright 会话，分类记录超时 |

原记录称 300 人、8,944 静态实例、784 draw calls、1,783,428 三角形；这些先视作**原报告数据**，本机重跑结果另存 `reports/reference-validation.json`，不能抄成验收结果。draw calls 包含多 pass/阴影，30fps 是捕获采样，不是实测运行帧率。

## 不照搬的决定

原需求没有要求无缝循环，Kimi 为适配检查器选择了往返相机和循环船道。初版默认非循环，仅当任务要求 loop 才检查首尾一致；否则不让测试工具改写用户的镜头意图。

原轨迹最终删除了检查图片和脚本，适合一次性演示打包；Agent 研发要保留证据和失败版本。初版保留它们，但只发布当前已验证候选。

首次采样、重复 seek、cold reload、file:// 都是必要的可执行检查。它们不证明历史真实性、全时域无穿模、完整交互可用性或优秀审美。当前自审由同一模型完成，不能称独立质量裁判。
