# 初版结构与边界

> 公开整理版 · 2026-11-25。保留成文时点的记录；计划、文献结果和本地实测请分别理解。 环境路径已泛化，未收录的附件已标注；发布范围见 [整理说明](../../PROVENANCE.md)。

交付：用户需求 → 单模型工具循环 → Three.js 源码 → 自包含 HTML → 真实浏览器时间采样 → 模型看图与局部修改 → 交付。

`animation_agent/runtime.py`、provider、process、skills 的通用能力复制自本地 `3d-printing-agent`，后续独立维护；没有依赖 CAD/GLB/3MF 工具。复用会话恢复、预算、工具参数诊断、成功图像发送记录、运行轨迹，不把固定六阶段变成工作流。

收尾预算采用通用 Agent 余量控制 + ToolRuntime 领域 hook：只有当前候选通过技术检查且源码/证据哈希仍有效时，临近 token、步数或墙钟余量才进入 finalization。宿主在请求前和批量工具调用之间停止可选抛光，只保留当前图片、自审和发布；不会自动改写视觉结论或正式交付。没有哈希候选状态的 generic runtime 保持 no-op。未交付的可恢复候选只作 diagnostic 指针，不属于 `output/`。

构建由宿主固定 esbuild 执行，生成代码的 package.json/build hooks 不执行；输入可以使用本地 Three.js 及 addons。场景脚本在浏览器执行，宿主编译只解析源码。Python 文件工具限制任务目录；候选源码、截图、报告和 output 由宿主管理；Node/Chromium 子进程剥离网关凭据，浏览器阻止网络请求。

这是可信本地作者的开发工具，不是恶意 JavaScript 的 OS 沙箱。候选存在任务目录下，操作系统层面仍可被有同等用户权限的进程修改；交付前的状态哈希会检查意外改动。未来接入任意 shell、第三方插件或用户远程上传代码前需要独立进程/容器隔离。

`init_scene` 固定一次任务契约，用户需改契约时开新任务；初版不实现复杂交互式追加需求。源码随时可改，必须重建后重验。技能文件按需读取，不重述内部 runtime 实现给最终动画用户。

浏览器核验六个采样时刻、A→B→A、重新加载、file://、首帧运动和可选 loop。统计包含真实 host 延时、可选场景统计，预览像素方差只用于发现明显空白。页面 console/error/network 记录保留。必要的技术完成条件与模型自审分开记载。

外层复用已有 agent-harness replay/metrics；固定题集覆盖简洁生成、晶格结构、粒子/人群、非循环镜头、修复和缺输入。指标是可复现性/工具行为/成本，艺术质量需要人看真实结果。初版不引入多 Agent、训练、CAD、生成模型资产服务、独立审美评分器、自动安装未知依赖。
