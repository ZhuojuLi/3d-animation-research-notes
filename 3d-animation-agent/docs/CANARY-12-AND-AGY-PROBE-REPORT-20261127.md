## 一、核心结论速览

1. **40 道高难题包（`20 CAD + 20 2D`，100% 自生 `16:9` 单视角参考图）全部通过 `P03–P07` 双轮“零隐藏考题”自审**，严格卡死 `difficulty ≥ 4/5`（CAD 强制 `4–10` 个水密分色零件、`≥ 60` B-rep 面、`0.0 mm³` 零穿模干涉；2D 强制 `≥ 3–8` 个 ES 模块、多分区工作台/叙事舞台、`2–3` 个业务级交互控件），彻底剔除“白布单个工件 / 空背景单图标”。
2. **`kimi-k3.1-pro`（`claude --bare` 纯净无额外系统提示词）在 `12` 道高难题（`5 CAD + 5 2D + 2 道小红书官方锚点`）上实现 `12 / 12 (100.0%)` 五维准入并导出 XHS-Ready 多模态 SFT 轨迹**：
   - **小红书官方锚点对标**：在小红书官方机械压机 `xhs_anchor_press_cad` 上首轮 **`26` 轮斩获 `0.960`**（`938` 个 B-rep 面，`0.0 mm³` 零干涉）；在小红书地质博物馆玛瑙展柜与抛光台 `xhs_anchor_agate_2d` 上首轮 **`113` 轮斩获 `0.910`**（`8` 个 ES 模块，主动查看 `26` 张关键帧/局部截图精修）。
   - **自造高难题表现**：5 道 CAD 胜出均分 **`0.906`**（最高 `0.952`，B-rep 面数达 `289–1,843` 面）；5 道 2D 胜出均分 **`0.949`**（其中轨道数字孪生调度台 `anim2d_v2_11` 拿到 **`1.000` 五维大满贯**）。
3. **AGY 纯净隔离沙盒盲测证实：只给任务与参考图、零额外解题提示，强模型同样自发涌现出类似 DeepSeek 的“看全局大图 → 看剖面/多状态/双视口图 → 定位几何/亚像素瑕疵 → 多轮返修”长程闭环能力**：
   - `cad_v2_09`（双级行星减速器剖切总成）：AGY 盲测得分 **`0.952`**，与 `kimi-k3.1-pro`（**`0.952`**）分毫不差；
   - `anim2d_v2_07`（四冲程 DOHC 发动机工作台）：AGY 盲测得分 **`0.9667`**（视觉/规约/稳定性/美学四项 `1.0` 满分），与 `kimi-k3.1-pro` 第 2 轮（**`0.9667`**）完全持平。
4. **人工复核产物并完成 5 项“验收防误杀 + `v2.1` 质量上限提示词”升级**：修复前序废分支导出误判、宿主机工具链路径脱敏、`cad_inspect.py` 90° 四分之一象限剖视与同轴爆炸图、2D 交互截图后误覆盖时间戳 Bug，以及小红书 `qwen-sft-6414` 四段式 `TOOLS.md` 解耦与末尾审美上限激发语。

## 四、验收策略自测捕获并闭环的 5 项工程升级

1. **前序废分支导出误判修复（`run_threejs_best_of_2.py`）**：允许 `logging_proxy_to_swift.py` 正常剥离短废分支，仅拦截 `compact` 断链污染，避免误杀高分主干。
2. **宿主机工具链路径全量脱敏（`logging_proxy_to_swift.py`）**：将工具回显中的宿主机字体/虚拟环境/浏览器缓存路径统一脱敏为 `/workspace`、`/opt/runtime`、`/home/user`，实现 **12/12 样本 `0` 路径泄露**。
3. **`cad_inspect.py` 90° 四分之一象限剖视 + 底板下沉同轴爆炸图**：彻底解决半切剖视误删前后面板、质心径向爆炸推偏同轴轴系两大“校验器乌龙”。
4. **2D 交互评测禁覆盖跳转时间 + `ordinary` 画像无 `#id` 语义控件发现（`xhs_v2_produce.py`）**：保留控件真实跳转时刻，支持自然口语题面自动发现滑块/下拉/按钮。
5. **小红书 `v2.1` 质量上限四段式提示词 + `P07` 三轴包络物理自洽核查（`xhs_v2_synth.py` & `remaining_30_v2_1.jsonl`）**：解耦工作区 `TOOLS.md`，每题强制收束于审美与工艺上限激发语，并在 `P07` 拦截子零件跨度与总包络不自洽矛盾。
